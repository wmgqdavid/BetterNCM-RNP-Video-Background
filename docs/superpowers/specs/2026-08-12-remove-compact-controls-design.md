# 0.2.2 移除精简播放控件设计

## 目标

移除 RNP Video Background 中与 RefinedNowPlaying Next 自带能力重复的“精简播放控件”，让底部播放栏、全屏和控制区显示完全由 RNP 管理。

## 改动

- 删除默认设置和标准化结果中的 `compactControls` 字段。
- 删除设置页复选框、状态同步、恢复默认值和运行期 body class 切换。
- 删除隐藏 `#main-player`、进度预览、音量及 RNP v3 控件的 CSS。
- 旧配置中残留的 `compactControls` 会在标准化时被自然丢弃，不影响视频背景的其他设置。

## 保持不变

视频背景、首帧切换、亮度和填充方式、视频声音、音乐同步、FFmpeg 自动检测与转换、RNP 歌词及 Overview 状态全部保持不变。

## 验证

回归测试明确禁止主程序和样式中出现精简控件字段、类名、文字及底栏选择器；同时继续运行全部原有转换与 RNP 保护测试，并重新校验安装包。
